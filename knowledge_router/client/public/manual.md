# 知识问答系统 · 使用手册

欢迎使用知识问答控制台。本手册介绍各页面的用途与操作步骤，帮助您完成问答测试、知识库维护与效果评测。

---

## 1. 这个产品能做什么

本系统用于**标准问答匹配**：

- 您事先录入「标准问题 + 回答」
- 用户提问时，系统用 AI **找出最匹配的标准问题**
- 匹配成功后，**直接返回已保存的回答**（不是临时让 AI 现写一段新答案）
- 可同时查看多个候选匹配及匹配程度，方便调试与评测

**连接状态**（页面右上角）：

- **已连接**（绿点）：可以正常使用
- **连接失败**（红点）：请联系管理员确认服务是否可用

## 2. 调试 · 问答

**入口**：左侧「调试 → 问答」

用于单条提问，快速查看系统能否匹配到正确的标准问题并返回答案。

### 界面说明

| 区域 | 说明 |
|------|------|
| 主区 | 显示匹配到的回答，支持 Markdown（标题、列表、图片等） |
| 右侧「提问」 | 输入问题、选择知识库、回答模型、返回候选数量 |
| 右侧「候选匹配」 | 各候选的匹配程度与对应标准问题 |
| 右侧「消耗时间 / Token」 | 本次问答的耗时与用量 |

### 操作步骤

1. 在右侧选择 **知识库** 与 **回答模型**
2. 设置 **Top K**（1–20，默认 5）：最多返回前几个候选
3. 输入问题，点击 **提问**，或使用快捷键 **Ctrl+Enter**
4. 在主区查看回答；点击候选卡片可跳转到对应回答

### 其他功能

- **清空**：清除当前问题与回答
- **随机问题**：从当前知识库已启用条目中随机抽一条问法填入输入框

## 3. 调试 · 召回度测试

**入口**：左侧「调试 → 召回度测试」

用于批量评测：准备一批测试问题，让系统自动匹配，再人工判断「是否找对了」，最后统计召回率。

### 界面说明

| 区域 | 说明 |
|------|------|
| 主区 | 测试问题列表，每条可查看回答、标注是否召回 |
| 顶部统计 | 总条数、已标注数、召回率、平均耗时、平均用量 |
| 显示条数 | 10 / 20 / 50 / 不限，控制一屏显示多少条 |
| 右侧栏 | 知识库、候选数量、回答模型；增删、运行、保存、导入、导出 |

### 推荐流程

1. 选择 **知识库**（会自动加载该库的历史测试记录）
2. 点击 **添加行** 逐条填写，或使用 **批量导入问题** 一次导入多条
3. 填写或编辑 **人工问题**（即您希望系统能答对的测试问法）
4. 点击 **批量运行**：
   - 若勾选了部分行 → 只运行选中且已填写问题的行
   - 若未勾选 → 运行所有尚未标注「是/否」的行
5. 点击 **查看回答** 查看系统给出的候选回答
6. 标注 **是否召回**（是 / 否 / 未标注）
7. 点击 **保存**，测试数据会随知识库一起保留
8. 点击 **导出 Markdown** 可下载评测报告

### 标注说明

- 标注为 **是**：卡片左侧显示绿色边线
- 标注为 **否**：卡片左侧显示红色边线
- **全选** 便于批量运行或删除

## 4. 管理 · 问题管理

**入口**：左侧「管理 → 问题管理」

维护知识库与 FAQ 条目：新增、编辑、启用/禁用、批量导入等。

页面为三栏：**知识库列表** | **标准问题列表** | **问题编辑器**

### 知识库操作

点击知识库区域的 **操作 ▾**：

| 操作 | 说明 |
|------|------|
| 新增知识库 | 创建新的知识库 |
| 刷新列表 | 重新加载知识库列表 |
| 重命名 | 修改知识库名称 |
| 重新加载索引 | 修改后若未立即生效，可手动刷新 |
| 删除知识库 | 删除整个知识库及其全部 FAQ（需确认） |

### 标准问题操作

点击标准问题区域的 **操作 ▾**：

| 操作 | 说明 |
|------|------|
| 新增问题 | 填写标准问题、其他问法、回答（Markdown） |
| 批量新增 | 按界面说明一次导入多条 FAQ |
| 刷新 / 全选 / 取消全选 / 反选 | 管理列表勾选 |
| 启用选中 / 禁用选中 | 控制该 FAQ 是否参与匹配 |
| 删除选中 | 批量删除 |

### 编辑与保存

- **表单**：编辑标准问题、其他问法、回答 Markdown（支持编辑与预览）、是否启用匹配
- **保存** 当前条目，或使用快捷键 **Ctrl+S**
- 保存后系统会自动更新，一般无需额外操作

## 5. 管理 · 文件管理

**入口**：左侧「管理 → 文件管理」

上传 PDF 或 Markdown、提取正文、编辑保存，为「问题生成」准备素材。

### 界面布局

| 区域 | 说明 |
|------|------|
| 左栏 | 文件树：源文件（PDF / Markdown）与提取后的 Markdown |
| 中栏 | Markdown 编辑（编辑 / 预览）或 PDF 操作提示 |
| 右栏 | 上传、保存、操作菜单、提取设置、进度 |

### 上传文件

支持上传 **PDF** 与 **Markdown** 文件。

### 从 PDF 提取正文

1. 在文件树中选择 PDF
2. 在右侧设置 **页码范围**（可添加多段，例如第 1–5 页、第 56–62 页）
3. 点击 **开始提取**
4. 系统会先识别页面内容，再用 AI 整理成 Markdown（所用模型在「设置 → 文档提取模型」中配置）
5. 完成后会自动打开提取结果，供您继续编辑

### 从 Markdown 源文件提取

选择源目录下的 Markdown 文件，指定 **行范围**，同样可提取为结构化 Markdown。

### 编辑与保存

1. 在文件树中选择提取后的 Markdown
2. 在中栏编辑或预览
3. 点击 **保存**
4. 若切换文件时有未保存修改，系统会提示确认

### 文件操作菜单

| 操作 | 说明 |
|------|------|
| 新建 Markdown | 创建新的空白 Markdown 文件 |
| 刷新 | 重新加载文件列表 |
| 重命名 | 修改文件名 |
| 删除 | 删除文件（需确认） |

## 6. 管理 · 问题生成

**入口**：左侧「管理 → 问题生成」

从 Markdown 中选取段落，自动生成 FAQ 问法并导入知识库。

### 界面布局

| 区域 | 说明 |
|------|------|
| 顶栏 | 选择目标知识库、新建知识库、刷新文件列表 |
| 左栏 | Markdown 文件列表 |
| 中左 | 行范围选择与已选段落列表 |
| 中右 | 带行号的 Markdown 阅读区（源码 / 预览） |

### 推荐流程

1. 选择 **导入知识库**
2. 在左侧点击要使用的 Markdown 文件
3. 设置「从第 X 行到第 Y 行」→ 点击 **添加选择**
4. 对每条已选段落：
   - 可手动填写标准问题与其他问法
   - 或点击 **自动生成问法**（使用「设置」中的 FAQ 生成模型）
5. 点击 **导入到知识库**

**典型流程**：文件管理上传 PDF → 提取 Markdown → 问题生成选段 → 生成 FAQ 问法 → 导入知识库 → 调试问答验证效果

## 7. 日志

**入口**：左侧「日志」

查看各功能模块的操作记录，便于了解近期做了什么、排查异常。

| 功能 | 说明 |
|------|------|
| 模块筛选 | 按功能分类查看（调试、问题管理、文件管理、问题生成、设置等） |
| 知识库筛选 | 查看特定知识库或全部 |
| 自动刷新 | 进入本页后定期更新（未暂停时） |
| 暂停 / 继续 | 暂停或恢复自动刷新 |
| 清空 | 清空全部日志（需确认） |
| 刷新 | 手动更新列表 |

## 8. 设置

**入口**：左侧「设置」

在此配置 AI 模型与提示词。**修改后请点击右上角「保存全部」**，配置才会生效。

### 8.1 回答模型

- 可添加 **多套** 模型（接口地址、密钥、模型名称、输出长度、随机性等）
- 「调试 · 问答」与「召回度测试」页可切换不同模型进行对比
- 至少保留一套；可勾选 **默认**

**使用本机 Ollama 模型时**：

- 填写本机 Ollama 的接口地址与模型名称
- **密钥** 留空
- **思考模式** 请选择 **关闭（Ollama 本地推荐）**

若本机尚未安装或未启动 Ollama，请联系管理员协助。

### 8.2 FAQ 生成模型

「问题生成」页 **自动生成问法** 所使用的 AI，与回答模型相互独立。使用 Ollama 时填写方式与上一节相同。

### 8.3 文档提取模型

从 PDF 提取并整理为 Markdown 时使用的 AI。使用 Ollama 时填写方式与上一节相同。

### 8.4 思考模式

| 选项 | 含义 |
|------|------|
| 默认 | 使用系统预设策略 |
| 关闭（Ollama 本地推荐） | 不输出思考过程，匹配更快；**本机 Ollama 务必选此项** |
| 开启 | 允许模型深度思考（部分云端模型适用） |

### 8.5 提示词

| 类型 | 用途 |
|------|------|
| 回答模型提示词 | 控制问答与召回测试中的语义匹配规则 |
| FAQ 生成提示词 | 控制如何根据回答正文生成标准问题与其他问法 |
| 文档提取提示词 | 控制 PDF 提取后如何整理 Markdown |

各区域可 **恢复默认提示词**；下方只读区域展示保存后将实际使用的规则预览。

## 9. 推荐工作流

### 9.1 从零建立知识库

1. **设置** → 配置回答模型（若要从文档建库，还需配置 FAQ 生成模型）
2. **管理 → 问题管理** → 新增知识库 → 手动录入或批量导入 FAQ
3. **调试 → 问答** → 试几条问题，看匹配是否正确
4. **调试 → 召回度测试** → 批量评测召回效果

### 9.2 从 PDF 建立知识库

1. **设置** → 配置文档提取模型、FAQ 生成模型及对应提示词
2. **管理 → 文件管理** → 上传 PDF → 设置页码 → 开始提取
3. **管理 → 问题生成** → 选择提取后的 Markdown → 选段落 → 自动生成问法 → 导入知识库
4. **调试 → 问答** → 验证效果
5. **调试 → 召回度测试** → 评测并导出 Markdown 报告

### 9.3 日常维护

- 修改 FAQ 后保存即可，一般会立即生效；若异常可尝试「重新加载索引」
- 在 **日志** 页查看近期操作
- 重要数据备份请联系管理员

## 11. 常见问题

**问：提问后没有回答？**  
答：请确认知识库中有已启用的 FAQ 条目；查看「候选匹配」是否全部未匹配；检查「设置」中回答模型的接口与密钥是否正确。

**问：召回度测试保存后，换天还能找到吗？**  
答：可以。数据与所选知识库绑定，再次选择同一知识库会自动加载历史记录。

**问：PDF 提取失败或很慢？**  
答：请检查「设置 → 文档提取模型」是否配置正确；查看文件管理右侧进度提示，或在「日志」页查看详情。

**问：本机 Ollama 模型无响应？**  
答：请确认本机 Ollama 已安装并正在运行、所需模型已下载；思考模式选 **关闭**；仍无法使用时请联系管理员。

**问：回答里的图片不显示？**  
答：请确认图片已正确上传并在回答 Markdown 中引用；仍无法显示请联系管理员。

**问：提示鉴权或密钥错误？**  
答：请在「设置」页检查对应模型的 API Key；本机 Ollama 模型无需填写 Key。
