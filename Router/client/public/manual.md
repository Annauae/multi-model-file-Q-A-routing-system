# 知识问答控制台 · 使用手册

欢迎使用知识问答控制台。本系统支持两种工作模式，用于搭建、调试和评测相机 FAQ 类知识库：

| 模式 | 说明 |
|------|------|
| **问答模型（LLM）** | 用 AI 语义匹配标准问题，命中后直接返回已保存的回答 |
| **RAG** | 向量 + 关键词混合检索，经 Rerank 排序后直出 FAQ 答案 |

多数页面右上角有 **模式切换**（问答模型 / RAG），切换后知识库、配置与操作相互独立。

**连接状态**（页面右上角）：

- **已连接**（绿点）：服务正常
- **连接失败**（红点）：请确认后端服务已启动

---

## 1. 调试 · 问答

**入口**：左侧「调试 → 问答」

单条提问，快速验证匹配或检索效果。

### 1.1 问答模型模式

| 区域 | 说明 |
|------|------|
| 主区 | 按置信度排序的候选回答（Markdown，含图片） |
| 右侧「提问」 | 问题、知识库、问答模型、Top K |
| 右侧「候选匹配」 | 各候选的匹配分数与标准问题 |
| 右侧「消耗时间 / Token」 | 本次问答耗时与用量 |

**操作**：

1. 选择 **知识库**、**问答模型**，设置 **Top K**（1–20）
2. 输入问题，点击 **提问** 或 **Ctrl+Enter**
3. 点击候选卡片可跳转到对应回答
4. **随机问题**：从当前库已启用条目中随机抽一条问法

### 1.2 RAG 模式

| 区域 | 说明 |
|------|------|
| 主区「RAG 回答」 | 检索到的 FAQ 条目完整预览（Markdown） |
| 主区「条目导航」 | 点击可滚动定位到对应条目 |
| 右侧 | 知识库、Top K、索引状态 |
| 右侧「消耗时间 / Token」 | 分阶段：Embedding、Rerank |

**操作**：

1. 选择 **RAG 知识库**，确认索引为 **索引就绪**（否则需先重建索引）
2. 点击 **问答**：完整 RAG 流程（检索 → Rerank → 直出 Top-1 FAQ 答案）
3. 点击 **检索**：仅检索排序，不返回答案正文
4. 右侧 **消耗 Token** 可查看 Embedding 与 Rerank 各阶段用量

**索引状态**：

| 显示 | 含义 |
|------|------|
| 索引就绪 | 可直接问答/检索 |
| 索引过期 | FAQ 或 Embedding 模型有变更，需点 **重建索引** |
| 未构建索引 | 从未建索引，需先重建 |

> 刷新页面**不会**清空索引；只有 FAQ 改动或 Embedding 模型变更才需重建。

## 2. 调试 · 召回度测试

**入口**：左侧「调试 → 召回度测试」

批量准备测试问题，自动运行后人工标注「是否召回」，统计召回率。

### 界面说明

| 区域 | 说明 |
|------|------|
| 主区 | 测试问题列表，每条可查看回答、标注是否召回；行末 **⋯** 可单条操作 |
| 顶部统计 | 总条数、已标注数、召回率、平均耗时、平均 Token |
| 工具栏 | **保存**（独立按钮）、**操作** 下拉（增删、导入、导出等） |
| 右侧 | 知识库、Top K、问答模型（LLM）或索引状态（RAG） |

### 行级操作（⋯ 菜单）

每条测试问题右侧 **⋯** 提供：

| 操作 | 说明 |
|------|------|
| 复制问题 | 将问题文本复制到剪贴板 |
| 清空结果 | 清除该行的运行结果与标注，保留问题文本 |
| 删除 | 移除该行（需再点 **保存** 才持久化） |

**RAG 模式** 工具栏 **操作 → 从问答模型复制**：将所选问答模型知识库的全部召回测试问题复制到当前 RAG 知识库（替换现有列表，自动保存）。

### 推荐流程

1. 选择 **知识库**（自动加载该库历史测试）
2. **操作 → + 添加问题**，或 **批量导入问题**（JSON 数组，每项含 `question` 字段）
3. 两种模式均可 **从 FAQ 采样** 测试问题
4. 点击 **批量运行**（勾选行优先；未勾选则运行未标注行）
5. 点击 **查看**：
   - LLM：查看置信度候选回答
   - RAG：查看完整 RAG 回答与来源条目
6. 标注 **是否召回**（是 / 否 / 未标注）
7. 点击 **保存** 持久化；**导出 Markdown** 下载报告

**标注颜色**：是 → 绿色边线；否 → 红色边线。

## 3. 管理 · 问题管理

**入口**：左侧「管理 → 问题管理」

维护知识库与 FAQ。左侧 **知识库** 栏顶部可切换 **问答模型 / RAG** 模式（FAQ 模式），其下为知识库列表与 **操作** 菜单。

布局：**知识库列表** | **标准问题列表** | **问题编辑器**

### 3.1 知识库操作

点击知识库区域 **操作 ▾**：

| 操作 | 说明 |
|------|------|
| 新增知识库 | 创建新库 |
| 刷新列表 | 重新加载 |
| 重命名 | 修改名称 |
| 重新加载索引 | 问答模型模式：刷新内存索引 |
| 从 RAG 导入 FAQ | **问答模型专用**：从 RAG 库复制 FAQ 并重载索引 |
| 从问答模型导入 FAQ | **RAG 专用**：从问答模型库复制 FAQ 并重建向量索引 |
| 删除知识库 | 删除整库（需确认） |

### 3.2 标准问题操作

顶栏 **操作 ▾** 提供批量操作：

| 操作 | 说明 |
|------|------|
| 新增 / 批量新增 | 添加 FAQ |
| 刷新 / 全选 / 反选 | 列表管理 |
| 启用 / 禁用选中 | 控制是否参与匹配或检索 |
| 删除选中 | 批量删除 |

### 3.2.1 单条问题操作（⋯ 菜单）

每条标准问题卡片右侧 **⋯** 提供：

| 操作 | 说明 |
|------|------|
| 重命名 | 修改标准问题文本（不打开完整编辑器） |
| 启用 / 禁用 | 切换该条是否参与匹配或检索 |
| 删除 | 删除该条 FAQ（需确认） |

点击卡片其他区域仍可打开完整 **问题编辑器**。

**RAG 模式** 顶栏右侧显示 **索引就绪 + 重建索引**（同一行：标识在左，按钮在右）。修改 FAQ 后若显示「索引过期」，需重建索引。

### 3.3 编辑 FAQ

- 编辑器支持 **Markdown 源码 / 预览** 分栏编辑
- **保存** 当前条目，或 **Ctrl+S**
- LLM 模式保存后一般立即生效；RAG 模式保存后需确认索引状态

## 4. 管理 · 文件管理

**入口**：左侧「管理 → 文件管理」

支持上传 **PDF、Markdown、TXT、Word（.docx）、HTML、JSON、Excel（.xlsx/.xls/.csv）** 等文件；提取、编辑与问题生成能力因格式而异。

页面有两种主视图：**文件网格**（默认）与 **文件预览/编辑**（点开某个文件后进入）。

### 支持的文件类型

| 类型 | 预览 | 直接编辑 | 转 Markdown | 直接问题生成 |
|------|------|----------|-------------|--------------|
| MD / TXT / HTML / JSON | 是 | 是 | 可选（行范围） | 是（按行） |
| Word (.docx) | 是 | 否 | 是（含 VLM 整理） | 是（按行） |
| Excel / CSV | 是 | 否 | 是（含 VLM 整理） | 否（须先转 MD） |
| PDF | 是 | 否 | 是（docling + VLM） | 否（须先转 MD） |

> 转换保留正文与图片，VLM 可提高可读性，**不保证版式与原文件一致**。含复杂图表的 Excel 建议先导出 PDF 再提取。

### 界面布局

#### 文件网格视图（默认）

| 区域 | 说明 |
|------|------|
| **顶栏** | **新建 MD**、**刷新**、**上传文件** |
| **左栏「文件」** | 两个分类气泡：**上传文件**、**转换文件**；气泡可展开/收起，显示该分类下的文件列表 |
| **右栏主区** | 两个分组区块，各以 **3 列网格卡片** 展示文件（图标、文件名、类型、行数）；卡片右侧 **⋮** 菜单可 **重命名 / 删除** |

**左侧列表与右侧网格的关系**：

- 点击左侧某文件 → **不会**打开预览，而是在右侧网格中 **滚动定位** 到对应卡片并短暂高亮
- 点击网格卡片（除 ⋮ 以外区域）→ 进入 **文件预览/编辑** 视图

#### 文件预览/编辑视图

进入某文件后，布局变为 **全宽预览区**（左侧文件栏隐藏）：

| 区域 | 说明 |
|------|------|
| **顶栏左侧** | **返回** + 文件名（如 `PDF：xxx.pdf`） |
| **顶栏右侧** | 按文件类型显示：**文件转 Markdown**、**问题生成**；可编辑文件另有 **保存** 与 **编辑 / 预览** 切换 |
| **主区** | 文件预览或 Markdown 源码编辑（PDF / Word / Excel 等为只读预览） |

**返回** 回到文件网格，不清除当前选中状态，便于左侧再次定位。

> 预览/编辑视图下 **不显示**「新建 MD」「刷新」「上传文件」。不可直接编辑的格式（如 PDF）**不显示「保存」**。

### modules 目录说明

`modules/` 存放提取或整理后的 Markdown，例如：

- `merged_*.md` — 从 PDF/Word/Excel 等提取合并的文档
- `module_l*.md` — 按行范围提取的片段
- `merged_faq_answers_kb1.md` — 当前知识库全部 FAQ 答案合集（便于通读与检索）

合集文件中的图片使用 `assets/` 路径，预览时会从 `documents/assets/` 或知识库 `kb_*/assets/` 加载。

### 文件转 Markdown

在 **文件预览/编辑视图** 中，对支持的源文件点击 **文件转 Markdown**（弹窗）：

1. 弹窗 **不再显示左侧选文件栏**，直接针对当前打开的文件
2. 按格式设置范围：PDF **页码**、文本 **行范围**、Excel **工作表 + 行范围**、Word **整文档**
3. 可选 **VLM 智能整理**（Word/Excel/HTML，推荐开启；PDF 已内置 VLM）
4. 转换完成后结果写入 `modules/`，可继续编辑保存

### 问题生成（弹窗）

在 **文件预览/编辑视图** 中，对支持 FAQ 生成的文件点击 **问题生成**：

1. 弹窗 **不再显示左侧选文件栏**，直接针对当前打开的文件
2. 选择 **问答模型 / RAG** 导入目标与知识库
3. 指定行范围 → **添加选择** → **自动生成问法** 或手动填写
4. **导入** 到知识库

### 文件操作汇总

| 操作 | 入口 |
|------|------|
| 上传 | 网格视图顶栏 **上传文件** |
| 新建 Markdown | 网格视图顶栏 **新建 MD**（创建后自动滚动到新文件） |
| 刷新文件列表 | 网格视图顶栏 **刷新** |
| 打开预览/编辑 | 点击网格卡片 |
| 重命名 / 删除 | 网格卡片 **⋮** 菜单 |
| 保存 | 文件预览/编辑视图顶栏（仅可编辑格式） |
| 返回网格 | 文件预览/编辑视图顶栏 **返回** |

## 5. 日志

**入口**：左侧「日志」

查看各模块操作记录，支持筛选与自动刷新。

| 筛选项 | 说明 |
|--------|------|
| 全部 | 所有模块 |
| 问答模型 | LLM 问答、匹配相关 |
| RAG | 检索、问答、索引重建等（含分步详细日志） |
| 问题管理 / 文件管理 / 问题生成 / 设置 | 对应功能操作 |

可按 **知识库** 过滤；支持 **暂停 / 刷新 / 清空**。

## 6. 设置

**入口**：左侧「设置」

顶栏切换 **问答模型 / RAG** 两套独立配置。**修改后请点击「保存全部」**。

### 6.1 问答模型模式

按 **模型 → 提示词** 交替排列：

| 配置项 | 用途 |
|--------|------|
| 问答模型 | 问答与召回测试的语义匹配（可多套，设默认） |
| 问答模型提示词 | 匹配规则 |
| FAQ 生成模型 | 文件管理 · 问题生成弹窗 |
| FAQ 生成提示词 | 问法生成规则 |
| 文档提取 / VLM 整理模型 | PDF 提取；Word/Excel/HTML 转 MD 时的 VLM 整理 |
| 文档提取提示词 | 文档整理规则 |

**本机 Ollama**：填写接口地址与模型名，**密钥留空**，**思考模式选「关闭」**。

### 6.2 RAG 模式

| 配置项 | 用途 |
|--------|------|
| Embedding 模型 | 文本向量化（变更后需重建索引） |
| Rerank 模型 | 检索结果重排序 |

Embedding、Rerank 不使用提示词，设置页不提供提示词配置。

## 7. 推荐工作流

### 7.1 问答模型：从零建库

1. **设置** → 配置问答模型
2. **问题管理** → 新增知识库 → 录入或批量导入 FAQ
3. **调试 · 问答** → 试几条问题
4. **召回度测试** → 批量评测并保存

### 7.2 问答模型：从 PDF 建库

1. **设置** → 文档提取模型、FAQ 生成模型
2. **文件管理** → 上传 PDF → 在网格中点击打开 → **文件转 Markdown** → 保存
3. 在同一文件视图中 **问题生成** → 选段 → 自动生成问法 → 导入知识库
4. **问答 / 召回度测试** → 验证

### 7.3 RAG：建库与评测

1. **设置（RAG）** → 配置 Embedding、Rerank
2. **问题管理（RAG）** → 新建 RAG 知识库 → 录入 FAQ，或 **从问答模型导入 FAQ**
3. 确认 **索引就绪**（否则 **重建索引**）
4. **调试 · 问答（RAG）** → 试问答与检索
5. **召回度测试（RAG）** → 采样 / 批量运行

### 7.4 日常维护

- LLM：改 FAQ 后保存即可
- RAG：改 FAQ 后若索引过期，点 **重建索引**
- 在 **日志** 查看近期操作与 RAG 分步详情

## 9. 常见问题

**问：RAG 提问后没有结果？**  
答：确认索引为「索引就绪」；FAQ 有已启用条目；Embedding / Rerank 模型配置正确。

**问：每次刷新都要重建索引吗？**  
答：不需要。索引持久保存在服务端，只有 FAQ 变更或 Embedding 模型变更时才需重建。

**问：RAG Token 消耗哪些阶段？**  
答：主要消耗 **Embedding** 与 **Rerank**，问答结果直出 FAQ 原文，不额外调用 LLM。

**问：LLM 提问后没有回答？**  
答：确认库中有已启用 FAQ；检查「设置 → 问答模型」接口与密钥。

**问：召回度测试数据会丢失吗？**  
答：不会。点击 **保存** 后与知识库绑定，再次选择同一库会自动加载。

**问：PDF 提取失败或很慢？**  
答：检查「设置 → 文档提取模型」；查看文件管理进度或「日志」详情。

**问：本机 Ollama 无响应？**  
答：确认 Ollama 已运行且模型已下载；思考模式选 **关闭**；密钥留空。

**问：回答里的图片不显示？**  
答：确认图片已上传且 Markdown 引用路径正确（相对 `assets/`）。FAQ 答案合集（`merged_faq_answers_kb*.md`）使用相同 `assets/` 路径，预览时会从 `documents/assets/` 或知识库 assets 目录加载。

**问：文件管理页左侧列表点击后为什么没打开预览？**  
答：左侧列表用于在右侧网格中 **滚动定位** 文件；要打开预览请在网格卡片上点击（⋮ 菜单除外）。

**问：PDF 预览时为什么看不到左侧文件栏？**  
答：进入文件预览/编辑视图后左侧栏会隐藏以留出全宽预览区；点 **返回** 可回到网格视图。

**问：使用手册在哪里？**  
答：页面右上角 **使用手册** 打开 **文档中心**，左侧可切换 **使用指南** 与 **开发者文档**。
