# 白平衡
白平衡可确保无论光源色彩如何，白色物体都显示为白色。推荐您在大多数光源下使用默认设定（自动白平衡，或<sup>WB</sup>A₁）；若使用自动白平衡不能获得预期效果，请按照下文所述选择其他选项。

## 调整白平衡
- 白平衡可使用📷菜单、照片拍摄菜单或视频拍摄菜单中的[白平衡]项目进行选择（🗋179、🗋284、🗋380）。

![白平衡菜单界面](assets/knowledge_p107-112_001.png)

- 在默认设定下，白平衡也可通过按住Fn按钮并旋转主指令拨盘进行选择（🗋85）。

![Fn按钮+主指令拨盘操作图示](assets/knowledge_p107-112_002.png)
![旋转主指令拨盘操作图示](assets/knowledge_p107-112_003.png)
![白平衡选择界面](assets/knowledge_p107-112_004.png)

✅ ☀A[自然光自动适应]
☀A[自然光自动适应]在人造光下可能无法产生预期效果。请选择<sup>WB</sup>A[自动]或适合光源的其他选项。

✅ 白平衡微调
在K[选择色温]以外的设定下，您可微调白平衡。使用📷菜单、照片拍摄菜单或视频拍摄菜单中的[白平衡]项目（🗋180、🗋285）。

✅ 摄影棚闪光灯灯光
<sup>WB</sup>A[自动]在大型摄影棚闪光灯组件照明下可能无法产生预期效果。请使用手动预设白平衡，或将白平衡设为<sup>WB</sup>⚡[闪光灯]并使用微调来调整白平衡。

📝 使用<sup>WB</sup>A或☀A拍摄时的色温
- 使用<sup>WB</sup>A[自动]或☀A[自然光自动适应]所拍照片的照片信息中会列出拍摄照片时照相机选择的色温。为K[选择色温]设定数值时可将其用作参考。

![照片信息色温显示界面](assets/knowledge_p107-112_006.png)

- 若要在播放过程中查看拍摄数据，请在播放菜单中选择[播放显示选项]>[更多照片信息]，并勾选[拍摄数据]旁边的复选框（☑）。

📝 色温
感知的光源色彩根据观察者的不同而异；有些可能带红色氛围而有些则呈现蓝色。色温是对光源色彩的一种客观衡量标准，以凯尔文（K）表示。色温越低，色彩越偏红（①）；色温越高，色彩越偏蓝（②）。

![色温数值与色彩偏向示意图](assets/knowledge_p107-112_007.png)

📝 选择一个色温
一般情况下，若您的照片带红色氛围或者想要使照片偏蓝，请选择较低值，若您的照片为蓝色调或者想要使照片偏红，请选择较高值。
